# context/

Put here, before the first planning session:
- `assignment.md`: the assignment and rubric, **verbatim**.
- `notes.md`: what the professor said about the project (paraphrased, dated). Do **not** commit full
  lecture transcripts or the textbook if the repo is public.
- `syllabus-notes.md`: grading weights and the course topics the project should connect to.
